Technology Trends Data Analysis Dashboard


Project Overview

This project analyzes survey data to identify trends in programming languages, databases, and platforms. The goal is to understand current technology usage and predict future demand.


Tools Used
 
	-Microsoft Excel
  	-Google Sheets
	  -Data Cleaning
 	 -Data Visualization


Key Analysis Performed
  -Cleaned and structured raw survey data for analysis
	
  -Performed exploratory data analysis (EDA)
	
-Built dashboards to visualize:
	
    -Technology usage trends
    -Developer demographics
    -Future technology preferences


Key Insights
  -Strong demand for Python and JavaScript
	
-Growth in cloud platforms such as AWS and Linux
    
  -Increasing popularity of modern databases like PostgreSQL
	
  -Majority of respondents fall within early to mid-career age groups


What I Learned
  -Data cleaning and preparation using Excel
	
  -Building dashboards to communicate insights
	
  -Identifying trends from real-world datasets
